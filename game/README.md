# AZ VELOCITY — Hyper Arcade Racing 🏎️💨

An Asphalt-style arcade racing game that runs entirely in your browser.
**Zero installs, zero internet needed** — everything (including the 3D engine)
is bundled in this folder.

## ▶️ How to play

**Just double-click `index.html`.** That's it — it opens in your default
browser and runs straight from disk.

> Works in Chrome, Edge, Firefox, Opera and Brave on Windows / Mac / Linux.
> For the smoothest experience, play in fullscreen (press `F11`).

## 🎮 Controls

| Key | Action |
|---|---|
| `W` / `↑` | Throttle |
| `S` / `↓` | Brake / reverse slow |
| `A` `D` / `←` `→` | Steer |
| `SPACE` | **Nitro boost** 🔥 |
| `SHIFT` | Drift / handbrake |
| `C` | Cycle camera (chase / far / hood) |
| `ESC` | Pause |

## 🚗 Content

- **10 hypercars** — each with unique top speed, acceleration, handling and
  nitro stats, previewed in a rotating 3D showroom garage.
- **6 world circuits** — Neon City (night), Sunset Dunes, Alpine Rush,
  Azure Coast, Volcanic Ridge and Emerald Forest. Every circuit is a unique
  procedurally-shaped loop with its own scenery, sky and lighting.
- **Race weekend features** — AI opponents with personalities, 3-2-1-GO
  countdown, lap counter, live position, race timer, minimap, wrong-way
  warning, results podium.

## ⚙️ Performance

Built for **low graphics power, high visual quality**:

- Open **Settings → Graphics** and pick *Low / Med / High*.
  *Low* renders at reduced resolution with shorter draw distance — it holds
  ~30 FPS even on a CPU-only software renderer, so any real GPU (including
  old integrated graphics) runs it at 60 FPS.
- No textures or models are downloaded — cars, tracks and even the asphalt
  texture are generated procedurally at load time.
- Sound is synthesized live with WebAudio (no audio files). Toggle it in
  Settings.

Your selected car, track and settings are remembered between sessions.
